# DevSecOps Tools

Мои инструменты для безопасности на Python.

## Инструменты

### Scanner.py
Сканер портов. Проверяет открытые порты на сервере.

### Secret_scanner.py
Сканер секретов. Ищет пароли, токены, ключи в коде.

### headers_scanner.py
Сканер security-заголовков. Проверяет защиту сайта.

## Технологии
- Python 3
- requests
- socket
- re
